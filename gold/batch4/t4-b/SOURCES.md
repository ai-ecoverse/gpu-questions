# t4-b held-out sources

The hand-labeled file contains 62 turns from two original public datasets and two owners. Both dataset cards declare CC-BY-4.0. Every record carries its pinned revision and session identifier. The sample contains 37 turns with an addressed question and 25 negatives, of which 23 are hard negatives. There are 29 boundary turns (a question containing `or` or selecting from a nearby list), three ambiguous labels, and no multi-select or default labels.

| Dataset | Pinned revision | Source format / agent | Labeled questions | Labeled negatives |
|---|---|---|---:|---:|
| [nmuendler/share-codex](https://huggingface.co/datasets/nmuendler/share-codex) | `368d63924356a773add5fe73f31ec014642ed0f1` | Local exported message-list sessions / Codex CLI, VS Code, MCP | 35 | 25 |
| [fdicastri/tandem-sessions](https://huggingface.co/datasets/fdicastri/tandem-sessions) | `ba36d1fe2834b807e15738002979b736a09c0bbd` | Original Markdown session record / Tandem orchestration | 2 | 0 |

The Codex file is 576 MB, above the older extractor's 150 MB download cap. `scripts/batch4_t4b_hf_extract.py` is an assignment-specific copy with only that cap raised. It downloaded the pinned file into `data/batch4/t4-b/codex/`. `data/batch4/t4-b/extract_codex.py` streamed its rows, kept only `source=codex` interactive `cli`, `vscode`, and `mcp` sessions, selected assistant message content rather than tool-call payloads, and scrubbed tails with the original extractor's scrubber. This yielded 812 candidates from 529 interactive sessions. The 60 labeled Codex turns are from the first 60 manually reviewed candidates after a fixed-seed shuffle prioritizing tails containing `?`; every label was decided from the complete stored tail. The Tandem Markdown transcript was downloaded under `data/batch4/t4-b/raw/` at the same pinned revision, and two human-facing turns were reviewed and added to `data/batch4/t4-b/queue.jsonl`.

One candidate from `nmuendler/share-codex` matched an earlier message tail in a prelabel leak check and was not used. No labeled turn was dropped for privacy. The final text and raw tails were scanned for email addresses, home paths, IP addresses, phone numbers, secrets, and the extractor's doubtful-content patterns; the scan found no hits. The final file also passes `scripts/check_batch4.py` with `OK`. No dataset contributes over 60 turns and no session over two.

Source search covered recent Hugging Face agent-trace, Codex, pi, opencode, and session uploads. Most remaining permissively licensed datasets from new owners were synthetic benchmark records, summaries without assistant text, token-only rollouts, unrelated noncoding agents, or mirrors of earlier data. In particular, `xio159/agentkit-sessions` has nine mostly demo workflow rows rather than interactive assistant turns; `kelikelibababian/mimir-agent-traces` publishes aggregate session statistics without messages; `sergiopaniego/opencode-rollout-trace` publishes token ID sequences rather than readable final replies; `thangquang09/agentic-coding-traces` contains numeric inference-benchmark traces; and `mondk/agentic-coding-traces` explicitly republishes other owners' files. These were excluded. This exhausted eligible sources with enough addressed questions to maintain the requested positive/negative mix before the approximately 400-turn and ten-owner targets could be reached.
